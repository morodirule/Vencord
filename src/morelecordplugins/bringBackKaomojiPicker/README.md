# Installation
See the [Vencord docs for installing custom plugins](https://docs.vencord.dev/installing/custom-plugins/) or
```cmd
cd (directory where you want to install the Vencord Repository)
git clone https://github.com/Vendicated/Vencord.git
cd Vencord
mkdir "src/userplugins"
cd src/userplugins
git clone https://github.com/Blankiiii/bringBackKaomojiPicker-Vencord.git
pnpm build
pnpm inject
```
